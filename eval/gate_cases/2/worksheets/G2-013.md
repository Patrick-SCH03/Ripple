## 11. 명세 모호와 고른 해석

- **A1. C-01 자재비 줄의 단위**(G2-007과 같음): 부재마다 한 줄로 냈다 — 새 스풀 +1,248,500, 빼는 스풀 −1,248,500. 합으로 한 줄이면 0원이라 줄이 없어지고(4-1 "0이면 줄을 내지 않음") 줄 집합이 달라진다. 총액은 같다.
- **A2. 금액 0인 재작업 줄**: 판넬조립 단계라 공수 0 → 작업반 묶음 없이 `R-B01:rework:S-001:P11C` 하나(0원). low·high도 0.
- **A4. 발주 단계 대표값이 계획에서만 옴**: PO-0128은 확인 진입일이 없고 관측은 미발주(10-20)뿐이라 대표 진입일을 계획 발주일 + 간격으로 잡았다(도메인 3절 규칙 3). 대표 단계가 있으므로 `known`으로 두었다(판단 불가는 대표 단계가 없을 때만).
- **A7. 선상 설치 요청인데 출구가 늦는 경우**: 6-3의 lag(탑재 → 출구) += d_on 때문에 출구가 탑재 EF + 1보다 이르지 않다. 자재가 탑재 뒤에 와도(도착 + 1 = 02-26 < 탑재 EF 02-28) 선상 설치 일수 하루가 출구를 하루 늦춘다고 읽었다(성질 "출구는 max(도착일 + 1, EF(탑재) + lag) + d_on보다 이르지 않다"와 일치). 그래서 선상 설치가 기다리는 방식보다 일정 이득이 없고 비용만 76,500 더 든다(선택지 `to_wait` 총액 차이 음수).
- **A8. 지연 파급 비용의 일수**: X = 출구 지연 1, L = 늘어난 인도 지연 0 → N = 1. 선상 설치 요청에서도 4-11을 그대로 적용했다.
- **A9. 곡선 사건의 확정일 일치**: 확정일 12-27이 선상 설치 수요가 처음 생기는 날이다(12-26 확정이면 도착 + 1 = 02-25 = 탑재 ES⁰라 수요 없음, C-03·출구 지연 없음). 경계 하루 차이가 판정을 바꾸므로 '>'(초과) 조건을 그대로 적용했다.
