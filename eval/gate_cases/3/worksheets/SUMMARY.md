- 계산 주체: 독립 손 계산자(엔진 코드·출력 미열람). 근거는 이 폴더의 docs/·rules/·params/·data/·cases/뿐.
- 보조 스크립트 `worksheets/scripts/engine.py`(파라미터·상태 함수·CPM), `evaluate.py`(변경 후 보기·규칙·비용 줄·변경 일정·곡선·보류 권고), `alt.py`(템플릿·판정·최적 조합·순위·출력), `show.py`(검토용). 명세 절은 각 파일 머리 주석. `uv run --no-project python -I alt.py`로 재현.
- 기준 일정(CPM)은 data의 공정·선후행·실적으로 직접 계산(비용·일정 6-2). 금액은 [최소 / 대표 / 최대], 원 단위 반올림(0.5는 0에서 먼 쪽).

## 명세 모호 목록(고른 해석)

- **A1 T5 적용 범위**: '요청 (가), 판 2장 이상'에만 정의 → 판 1장 요청(G3-001·002)에는 해당 없음으로 보고 omitted에 넣지 않음(omitted 이유 넷 중 맞는 것이 없음).
- **A2 보류 반영의 '가공' 진입일**: 가공 = 소비 공정 착수(기준 일정 ES⁰)인데 보류로 입고가 그 뒤로 밀리면 가공 = max(ES⁰, 보류 입고일)로 둠. G3-002(기간 밖)·G3-005(값 동일) 결과에 영향 없음.
- **A3 d_B 겹침(비용·일정 6-3)**: 재작업 일수가 운반 공정 a*의 추가 일수와 관문 R_B 양쪽에 들어간다. a*가 탑재 자체인 날엔 탑재가 두 번 늦어지는 셈(G3-003 11-19 출구 22일, G3-004 T2·T4 11-30~12-01). 명세 문장대로 두었고 확정일 값·총액·순위엔 영향 없음.
- **A4 마감일과 최소 시나리오(G3-005)**: domain 7절 "A(t) 범위 = 시나리오별 차이의 최소~최대"를 그대로 써서, 최소 시나리오만 오르는 날(제작 0.4 → 입고 0.45)도 추가손실 > 0으로 봄 → REQ·T2·T5 `confirm_now`. 'high 시나리오 차이만'으로 읽으면 `by_date 2026-11-07`. **확신 낮음**.
- **A5 보류 권고 '피하는 손실 범위의 최대값(최대 시나리오의 값)'**: 세 시나리오 차이의 최대값으로 읽음. 다섯 사례 모두 해석 차이가 결과를 바꾸지 않음(G3-002는 대표값도 양수, G3-005는 모두 0).
- **A10 근거 없는 발주의 가공 판정(G3-003 PO-0046)**: 발주 근거가 전혀 없어도 소비 공정이 착수했으면 가공으로 '정해진다'(domain 3절) → 판단 불가 아님, 줄은 known.
- **A15 설계자 확인 대안의 비율**: T4(G3-004)는 ρ = 1.0이 계산되지만 README대로 null.
- 보류 가능 기간은 '보류 없는 상태 함수의 입고 대표 진입일'로 계산하고(G3-002: 01-05 → h 18), 보류 곡선은 기준일에 아직 안 들어간 단계(대표 진입일 > 기준일)를 h일 미룸.
- 새 부재 임시 ID의 정규형은 사례 입력의 연산 필드 6개(add_part)·4개(thickness·grade)가 전부라고 보고 계산(기대값엔 ID가 들어가지 않음).
- R-T01의 '원래 단가'는 공급 품목 단가, 새 규격 LT'는 '변경 뒤 (분류·강종·두께) 규격의 std_lead_time → 없으면 공급 발주 리드타임' 순(모든 사례에서 발주 리드타임이 쓰임).

## 확신이 낮은 값

1. **G3-005 마감일(REQ·T2·T5 confirm_now)** — A4 해석에 따라 by_date 11-07로 바뀔 수 있음. 총액·순위·권고·날짜별 구간은 영향 없음.
2. **G3-002 REQ 최적 조합의 보류(PO-0108 18일, 788,237)** — 보류 가능 기간(LS − 입고 대표일)과 보류 반영(단계 밀기) 해석에 의존. 보류 없이 10-30 확정이면 977,045.
3. **G3-005 T1 PL-008 패널 수 N = 4**(3.5014, .5 경계 근접) → qty 0.661. N = 3이면 qty 0.496, T1 총액이 약 56만 원 줄지만 순위는 같음.
4. **재작업 줄 금액**: 몫마다 반올림해 더해 ±수 원 차이 가능. D_B는 세 계수를 넷째 자리, 곱을 여섯째 자리에서 반올림(G3-001 1.846937, G3-003 1.372493, G3-004 1.06656 / T31C 1.191745, G3-005 1.180551).
5. **G3-003 PO-0046#1**: 엔진이 판단 불가로 다루면 po_change 줄이 state_unknown(대표값 같음, 최소값 차이 가능).
6. 날짜별 구간·최적 조합은 곡선의 '값이 같으면 이른 날·보류 적은 쪽' 규칙을 그대로 따름. G3-005의 12-04 교차(REQ 8,360,019 vs T1 7,605,978)는 재작업 단계가 대조립으로 넘어가는 날에 생김.
7. 출구 지연은 확정일에 모두 0이지만 곡선 뒤쪽(탑재 뒤 확정)에서 크게 늘어남(G3-003 최대 46일, G3-004 T2 40일·T4 44일, G3-005 28일) — 관문 정의(6-3)와 a*·R_B 겹침(A3)에 민감.
