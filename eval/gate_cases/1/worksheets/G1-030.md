# G1-030 작업지 (계산자 B)

## 1. 입력
- 연산: `remove_part` S-001:F11C-ST-003 (1건)
- 기준일 2026-10-20, 확정일 2026-12-19 → **판정일 t = 2026-12-19**, 탐색 기간 60일(창 = 12-20 ~ 2027-02-17)
- 대상 부재(빼는 부재): S-001:F11C-ST-003. 빠지는 부재에서 출발하는 규칙은 원본 지도 관계로.

## 2. 자료
- 부재: stiffener, 블록 S-001:F11C, HP320x12-AH36(분류 section, AH36, 12.0), qty 0.17, 도면 DWG-F11C-H01@A(있음).
- 연결(원본): fillet_weld BR-008, PL-001.
- 공급 품목: **PO-0104#2**(HP320x12-AH36, 부재 ST-003·ST-014, 소비 S-001:F11C:sub_assembly).
  - PO-0104: 계획 발주 10-10, 자재 확보 +20, 제작 +37, 입고 +69. 확인 진입일 **ordered 10-11**. 관측 [(ordered, 10-20)].
- 블록 F11C: 모든 공정 미착수, 소조립 계획 2027-01-07(선행 없음) → ES⁰ 2027-01-07 > t.
- 같은 규격(HP320x12-AH36) 다른 품목: PO-0013#2(E21C), PO-0032#1(A11C), PO-0043#2(B31P), PO-0057#2(S31P), PO-0064#3(S31S), PO-0084#1(T31C), **PO-0126#1**(F31C, 부재 F31C-ST-018).
  - PO-0126: 계획 발주 **11-13**, +12/+26/+64, 확인 없음, 관측 [(not_ordered, 10-20)]. 소비 공정 S-001:F31C:sub_assembly 계획 2027-02-01(선행 없음, 실적 없음).

## 3. 판정일 단계 계산
### PO-0104#2
- 발주: 확인 10-11(기준일 전) → 대표 10-11.
- 자재 확보: 하한 = 발주 관측 10-20 + 1 = 10-21, 상한 없음. 계획 = 10-11 + (20−0) = 10-31 ≥ 하한 → 대표 10-31.
- 제작: 10-31 + (37−20) = 11-17. 입고: 11-17 + (69−37) = **12-19**.
- t = 12-19: 가장 이른 단계 발주(확인) → '발주 이상' **근거로 참**. 가장 늦은 입고. 대표 단계 = **입고**(입고 대표 진입일 12-19 ≤ 12-19, 소비 공정 F11C 소조립 ES⁰ 2027-01-07 > t라 가공 아님).
### 블록 F11C
- 공정 착수 전(소조립 ES⁰ 2027-01-07 > 12-19) → '소조립 이상' 거짓.
### PO-0126#1 (R-M01 나 후보)
- 모든 단계 하한 10-21(미발주 관측 10-20 + 1). 계획: 발주 11-13 → 자재 확보 11-25 → 제작 12-09 → 입고 2027-01-16. t = 12-19: 대표 단계 = **제작**(< 입고). 소비 공정 F31C 소조립 ES⁰ = 2027-02-01.

## 6. 명세 모호·확신
- B-3: PO-0104#2 입고 대표 진입일(12-19)이 판정일과 **같은 날**. 진입일 당일을 그 단계로 보아 '입고' → (나) 탐색이 열림. 하루만 앞이었으면(12-18) 제작이라 탐색이 없어 PO-0126#1 영향이 빠진다. 경계값이라 확인 대상.
- B-2: ③의 시계를 기준 일정 ES⁰로 봄. PO-0126#1 소비 공정은 선행이 없어 계획 착수일 = ES⁰(2027-02-01)이라 시계 선택과 무관.
- R-M01 (나) ②의 '대표 단계'는 PO-0126이 미발주 관측 뒤 계획으로 추정한 값(제작). 어느 단계든 입고 전이면 되므로 계획 세부와 무관.
- 확신: **중간**(B-3 당일 경계 + (나) 후보 판정이 걸림).
