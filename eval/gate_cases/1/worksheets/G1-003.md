- 연산: `equipment_spec` S-001:P11C-VLCS-001 VL-GLOBE-DN100-16K → VL-BALL-DN100-16K (G1-002와 같은 연산)
- 기준일 2026-10-20, **확정일 2026-12-05 → 판정일 = 2026-12-05** (기준일 뒤 근거는 쓰지 않고 10-20까지의 근거·계획으로 추정, 전파 9절)

## 1. 대상 부재 자료
G1-002와 같다(밸브 P11C-VLCS-001, 블록 P11C, 도면 DWG-P11C-CS-P01@A, 배관 연결 SPCS-001·SPCS-002, 공급 PO-0130#3, 새 규격 (DN100, 16K) = 옛 규격).

## 2. 판정일(12-05) 단계 계산

**PO-0130#3** (domain 3절 규칙 2·3)
- 근거: 관측 not_ordered@10-20 뿐. 확인된 진입일 없음. 계획: 발주 11-30, 자재 확보 +10, 제작 착수 +19, 입고 +37.
- E[ordered]: 하한 10-21(미발주 관측 다음 날), 상한 없음, 대표 = 계획 발주일 11-30(범위 안, 계획 이탈 아님).
- E[material_secured] 대표 = 11-30 + 10 = 12-10, E[in_fabrication] = 11-30 + 19 = 12-19, E[received] = 11-30 + 37 = 2027-01-06.
- 12-05의 세 값: 확실히 들어간 단계 = 미발주(발주를 증명하는 근거 없음), 들어갔을 수 있는 단계 = 입고까지(하한 10-21 ≤ 12-05), **대표 단계 = 발주(ordered)** (11-30 ≤ 12-05 < 12-10).
- 문턱 질문 "발주 이상인가": 근거로 정해지지 않음 → 대표 단계로 답 → **참**(판단 불가 아님).
- 소비 공정 P11C:pre_outfitting ES⁰ = 2027-01-26 > 12-05 → 가공 아님.

**블록 P11C @12-05**: sub_assembly ES⁰ = 12-07 > 12-05 → 공정 착수 전. 강재 입고 여부와 무관하게 소조립 전 → 거짓.

## 6. 명세 모호·확신

- (명세 모호 A1) 판정일이 기준일 뒤일 때 "근거로 정해지면 그대로, 아니면 대표 단계" — 12-05에는 근거(10-20 미발주 관측)가 '발주 이상'을 긍정도 부정도 못 하므로 대표 단계(계획 발주일 11-30 경과)로 답했다. 계획 발주일이 판정일보다 앞이므로 참. 다른 읽기(근거가 '미발주'를 마지막으로 관측했으니 미발주 유지)는 domain 3절 규칙 3(계획으로 대표값)과 맞지 않아 택하지 않았다.
- 확신 중간~높음(판정일이 기준일 뒤인 유일한 사례라 단계 추정 규칙 해석에 걸려 있음).
