# G1-022 작업지 (계산자 B)

## 1. 입력
- 연산: `equipment_spec` S-001:E21C-VLBW-001 VL-BUTTERFLY-DN200-10K → VL-CHECK-DN200-10K (1건)
- 기준일 2026-10-20, 확정일 없음 → **판정일 t = 2026-10-20**, 탐색 기간 60일
- 대상 부재: S-001:E21C-VLBW-001(valve). 변경 후 보기: 규격을 VL-CHECK-DN200-10K로 봄. from_spec_id = 지도 규격 ✓.

## 2. 자료
- 부재: valve, 블록 S-001:E21C, 계통 ballast, 도면 DWG-E21C-BW-P01@A(있음), 두께·강종 없음.
- 연결: pipe_joint E21C-SPBW-001, E21C-SPBW-002(둘 다 SP-DN200-S40).
- 규격: 옛 VL-BUTTERFLY-DN200-10K (DN 200, 10K, ea, 5,114,000) / 새 VL-CHECK-DN200-10K (DN 200, 10K, ea, 4,216,000) — 둘 다 지도에 있고 DN·압력 등급 네 값 모두 있음.
- 공급 품목: **PO-0133#1**(VL-BUTTERFLY-DN200-10K, 부재 VLBW-001·003, 소비 S-001:E21C:pre_outfitting).
  - PO-0133: 계획 발주 10-01, 자재 확보 +9, 제작 +12, 입고 +30. 확인 없음. 관측 [(not_ordered, 09-22), (not_ordered, 09-30)].
- 블록 E21C 공정: 소조립 실적 09-18~10-04, 판넬조립 10-04~10-16, **대조립 실적 착수 10-19**(미완), 선행의장 계획 11-12(ES⁰ 11-13), …

## 3. 판정일 단계 계산
### PO-0133#1
- 모든 단계 하한 = 10-01(미발주 관측 09-30 + 1), 상한 없음. 기준일 10-20 당일 관측 없음 → 계획 추정에 기댐(domain.md 3절).
- 대표(계획): 발주 10-01 → 자재 확보 10-10 → 제작 10-13 → 입고 10-31. 계획 이탈 없음.
- t = 10-20: 가장 이른 미발주, 가장 늦은 입고 → 근거로 미정 → **대표 단계 = 제작**(10-13 ≤ t < 10-31) → '발주 이상' 참. 소비 공정 선행의장 ES⁰ 11-13 > t → 가공 아님.
### 블록 E21C
- 대조립 actual_start 10-19 ≤ 기준일 → ES⁰ 10-19 ≤ t → **블록 단계 = 대조립** ≥ 소조립.
