## 3. 판정일 단계 계산
### PO-0027#1
- 확인: 발주 08-12, 자재 확보 08-26, 제작 09-13(모두 기준일 전).
- 입고: 확인 없음. 하한 = 제작 단계로 관측된 마지막 날(10-20)+1 = **10-21**, 상한 없음. 계획 = 제작 확인일 09-13 + (68−32) = 10-19 < 하한 → **계획 이탈, 하한 10-21로 조임** → 입고 대표 진입일 10-21.
- t = 11-08: 가장 이른 단계 제작(확인), 가장 늦은 단계 입고(하한 10-21 ≤ t). 근거로 미정 → **대표 단계 = 입고**(10-21 ≤ 11-08). 소비 공정 소조립 ES⁰ 11-09 > 11-08 → 가공 아님.
### 블록 A11C
- 기준 일정: 소조립 ES⁰ = max(계획 11-09, 기준일+1) = 11-09 > t → 공정 착수 전. 강재 품목(PO-0026·0027·0032·0033 등) 대표 단계로 모두 입고 → 강재 입고. 어느 쪽이든 '소조립 이상' = **거짓**.

## 6. 명세 모호·확신
- **B-1(명세 모호)**: R-M01 (나) ② "판정일에 '입고' 미만(대표 단계 기준)" — 다른 품목(PO-0099#1)의 대표 단계가 없을 때. 고른 해석: 대표 단계가 없으면 ②를 만족한다고 할 수 없어 후보에서 뺌("모르면 영향을 낸다"는 R-T01·R-M02·R-B01의 단계 조건에만 적힌 규칙이고 R-M01에는 "단계를 모르면 찾지 않는다"는 보수적 방향이 적혀 있음). 반대 해석(모름 = 입고 전으로 봄)이면 PO-0099#1 reallocate_stock이 추가된다.
- B-2: ③의 '착수 예정일' 시계는 기준 일정 ES⁰로 봄(비용·일정 편 1절 "영향 보고도 같은 시계"). PO-0099#1은 계획 착수일 = ES⁰ = 2027-01-07 = t+60으로 창 끝 포함 여부도 걸리지만, B-1로 어차피 제외.
- B-11: PO-0027 입고 계획(10-19)이 관측 하한(10-21)보다 앞 → 계획 이탈로 하한에 조임(3절 규칙 3). 그래서 11-08 대표 단계가 '입고'가 되어 (나) 탐색이 열림.
- 확신: **중간**(B-1 때문. 영향 집합 자체는 어느 해석이든 PO-0099#1 한 건 차이).
